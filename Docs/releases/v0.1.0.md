T-Utilities 첫 릴리스입니다. 자주 쓰는 메뉴 막대 유틸리티를 하나의 앱으로 모았습니다. macOS 26 이상, Apple Silicon 전용입니다.

## 모듈

설정 → 팝오버에서 모듈을 켜고 끄고 순서를 바꿀 수 있습니다. 끈 모듈은 중지되고 메모리에서 해제됩니다.

- **Clipboard** (CopyNinja 기반): 클립보드 기록, 검색, 빠른 슬롯(⌘1–0), 이미지 OCR, 훑어보기. ⌘⇧V로 열기/닫기. 항목에서 Return을 누르면 바로 붙여넣는 옵션(기본 꺼짐).
- **Awake**: Mac 잠자기 방지 — 수동(기본 3시간) / 자동(Claude·Codex·Cursor·Paseo 에이전트가 작업 중일 때) / 끔. 뚜껑을 닫아도 깨어 있게 할 수 있고, 배터리 20% 이하·발열 시 자동으로 해제합니다. 메뉴 막대 아이콘이 커피잔으로 상태를 보여 줍니다.
- **Clock**: 메뉴 막대에 두 번째 시간대를 24시간 형식으로 표시 (예: `NY 00:33`).
- **Windows** (Rectangle 기반): 최대화 ⌃⌥↩, 다음/이전 디스플레이 ⌃⌥⌘→ / ⌃⌥⌘←.
- **Cable** (WhatCable 기반): USB-C 포트·케이블·충전기 정보. 팝오버의 USB-C 행에서 포트별 상세(Thunderbolt 구성, 디스플레이 포함)를 볼 수 있습니다.
- **Mouse** (LinearMouse 기반, 기본 꺼짐): 포인터 속도·가속, 측면 버튼 → 바탕화면 보기 / Mission Control, 휠 반전·줄 단위 스크롤, Logitech 마우스 배터리(HID++) 표시.

## 그 밖에

- 하루 한 번 새 버전을 확인하고, 설정 → 일반에서 눌러서 설치할 수 있습니다.
- 설정 → 일반 → "오픈소스 라이선스"에서 사용한 오픈소스의 라이선스를 볼 수 있습니다.

## 설치

`brew install --cask mordol/tap/t-utilities` 또는 아래 zip을 받아 [INSTALL.md](https://github.com/mordol/T-Utilities/blob/main/INSTALL.md)를 따라 설치하세요. Clipboard 붙여넣기와 Windows·Mouse 기능에는 손쉬운 사용 권한이 필요합니다.
