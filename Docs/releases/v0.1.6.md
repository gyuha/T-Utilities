## 새 기능

- **Switcher 모듈 (새 모듈, 기본 꺼짐, 실험적 — 테스트 필요)** (#21)
  - Windows의 Alt+Tab처럼 창 단위로 전환합니다. ⌥를 누른 채 Tab을 누르면 창 썸네일 목록이 뜨고, Tab(⇧Tab은 반대로)이나 ←/→로 고른 뒤 ⌥를 놓으면 그 창으로 전환합니다. Esc는 취소, 클릭으로도 고를 수 있습니다.
  - 설정 → Switcher에서 단축키를 ⌘Tab으로 바꾸면 macOS 앱 전환기 대신 동작합니다.
  - 현재 데스크톱(Space)의 창과 최소화된 창이 나옵니다. 썸네일은 전환기를 열 때만 찍습니다.
  - 손쉬운 사용 권한이 필요하고, 썸네일을 보려면 **화면 기록** 권한도 필요합니다 (설정 → Switcher → "화면 기록 허용하기…"). 권한이 없으면 앱 아이콘과 창 제목으로 표시합니다.
  - alt-tab-macos의 아이디어를 참고해 새로 작성했습니다 (코드는 사용하지 않음).
  - ⚠️ **아직 실제 기기에서 충분히 테스트하지 못한 기능입니다.** 써 보시고 문제가 있으면 [이슈](https://github.com/mordol/T-Utilities/issues)로 알려 주세요. 특히 ⌘Tab 대체, 다른 앱 창으로의 전환, 썸네일 표시를 확인해 주시면 다음 버전에서 고치겠습니다. 문제가 생기면 설정에서 모듈을 끄면 원래대로 돌아갑니다.
- **Stats: 팝오버 안에서 펼치는 대시보드** (#18)
  - Stats 행을 누르면 메뉴 대신 팝오버 안에서 펼쳐집니다. CPU · 메모리 · 디스크는 막대와 값으로, 네트워크는 ↓/↑ 속도로 보여 주고, 그 아래 CPU · 메모리 상위 5개 프로세스와 "활동 모니터 열기"가 있습니다. 펼침 상태는 기억합니다.
  - 측정은 팝오버가 열려 있는 동안만 합니다 (펼친 상태에서는 2초마다 갱신). 접혀 있을 때는 CPU와 메모리만 읽습니다.
  - 설정 → Stats에서 항목마다 켜고 끌 수 있습니다. GPU 사용률은 공식 API가 아닌 값을 읽어 macOS 업데이트 후 깨질 수 있어 기본으로 꺼져 있습니다.
  - 네트워크는 Wi-Fi · 이더넷 같은 실제 인터페이스만 합산해서, VPN을 켜도 같은 트래픽을 두 번 세지 않습니다.
- **클립보드 팝오버 크기 조절** (#15, #16 @gyuha)
  - 기본 크기가 커졌고(폭 420, 목록 높이 560), 팝오버 오른쪽 아래 구석을 끌어 폭과 목록 높이를 바꿀 수 있습니다. 바꾼 크기는 기억합니다.
  - 화면 아래로 넘치지 않게 멈추고, 작은 화면에서 열면 화면에 맞게 줄어듭니다.
- **사전 창 크기 조절** (#15, #16 @gyuha)
  - 기본 크기가 커졌고(480×700), 가장자리를 끌어 크기를 바꿀 수 있습니다. 다시 열면 마지막 크기와 위치(화면 기준)로 열립니다.

## 버그 수정

- 팝오버에서 Stats나 Cable 메뉴를 띄웠다 닫은 뒤 바깥을 눌러도 팝오버가 닫히지 않던 문제를 고쳤습니다 (#19, #20 @gyuha).
- 사전 창 크기를 조절한 뒤 ESC나 바깥 클릭으로 닫히지 않던 문제를 고쳤습니다.
- 직접 빌드한 앱(다른 서명)에서 업데이트하면 "서명이 일치하지 않는다"는 오류만 나오던 것을, 직접 빌드한 앱이라 자동 업데이트가 안 된다고 안내하고 릴리스 페이지로 갈 수 있게 했습니다.

## 업데이트 방법

- v0.1.2 이상: 팝오버의 **New update** 버튼 또는 설정 → 일반 → "지금 확인".
- Homebrew: `brew upgrade --cask t-utilities` (앱을 종료한 뒤 실행하세요).
