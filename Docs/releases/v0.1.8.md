## 버그 수정

- **Mouse: 일부 마우스에서 포인터 속도·가속이 적용되지 않던 문제** (#23, 제보 @gyuha)
  - 지금까지는 macOS가 "마우스 가속" 방식으로 보고하는 마우스에만 속도·가속을 적용했습니다. 다른 방식으로 보고하거나 방식을 보고하지 않는 마우스는 아무 표시 없이 건너뛰어, 슬라이더를 움직여도 속도가 그대로였습니다.
  - 이제 LinearMouse와 같은 방식으로 마우스와 포인터 장치를 모두 찾고, 장치마다 맞는 가속 값에 적용합니다. 트랙패드는 지금처럼 건드리지 않습니다.
  - ⚠️ 이 수정은 해당 마우스로 직접 확인하지 못했습니다. 업데이트 후에도 속도가 바뀌지 않으면 아래 설정 화면의 표시 내용과 함께 [#23](https://github.com/mordol/T-Utilities/issues/23)에 알려 주세요.

## 개선

- **Mouse 설정에 적용 상태 표시**
  - 설정 → Mouse → 포인터에 속도·가속이 적용된 마우스 이름이 "적용 중: 마우스 이름"으로 나옵니다.
  - 마우스를 찾지 못하면 "감지된 마우스가 없습니다", macOS가 값을 받아들이지 않으면 "적용 실패"로 표시해, 왜 속도가 안 바뀌는지 바로 알 수 있습니다.

## 업데이트 방법

- v0.1.2 이상: 팝오버의 **New update** 버튼 또는 설정 → 일반 → "지금 확인".
- Homebrew: `brew upgrade --cask t-utilities` (앱을 종료한 뒤 실행하세요).
