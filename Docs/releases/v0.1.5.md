## 새 기능

- **Windows: 수정키 + 더블클릭으로 창 최대화 ↔ 이전 크기** (#12, #14 @gyuha)
  - 수정키 드래그의 수정키(기본 ⌥)를 누른 채 창 안 어디서든 더블클릭하면, 메뉴 막대와 Dock을 뺀 화면 전체로 창을 키웁니다. 다시 더블클릭하면 원래 크기와 위치로 돌아갑니다. Rectangle의 동작을 참고했습니다.
  - ⌃⌥↩(최대화) 단축키와 같은 기능이라, 단축키로 키운 창을 더블클릭으로 되돌리거나 그 반대로 해도 됩니다. 키운 뒤 창을 옮기거나 크기를 바꿨다면 다시 최대화합니다.
  - 수정키 없는 더블클릭, 오른쪽 버튼 더블클릭, 세 번 클릭은 지금처럼 동작합니다.

## 개선

- **충돌 앱 안내에 Easy Move+Resize 추가**: 이 앱이 실행 중이면 수정키 클릭을 먼저 가져가서 수정키 드래그·더블클릭이 동작하지 않습니다. 이제 실행 중이면 설정 → 일반에 충돌 앱으로 표시됩니다.

## 개발

- Xcode 26.1(Swift 6.2)에서도 테스트가 빌드되도록 테스트 코드 두 곳을 고쳤습니다.

## 업데이트 방법

- v0.1.2 이상: 팝오버의 **New update** 버튼 또는 설정 → 일반 → "지금 확인".
- Homebrew: `brew upgrade --cask t-utilities` (앱을 종료한 뒤 실행하세요).
