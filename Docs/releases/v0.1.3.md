## 개선

- **유휴 CPU 사용량 감소** — Cable 모듈이 15초마다 포트 정보를 새로 읽던 것을, 앱 시작 때와 팝오버·Cable 설정을 열 때만 읽도록 바꿨습니다. 모든 모듈을 켠 유휴 상태 CPU가 약 0.43% → 0.11%로 줄었습니다.
- **Awake 수동 시간 선택** — 수동 유지 시간을 `1시간 · 3시간 · 무제한` 세 버튼으로 고르게 했습니다. 기존에 8시간으로 저장돼 있었다면 3시간으로 바뀝니다.
