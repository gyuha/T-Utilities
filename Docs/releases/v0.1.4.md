## 새 기능

- **Windows: 수정키 드래그로 창 이동·크기 조절** (#6, @gyuha)
  - 수정키(기본 ⌥)를 누른 채 창 안 어디서든 끌면 창이 이동하고, 오른쪽 버튼으로 끌면 커서가 있는 모서리 쪽으로 크기가 조절됩니다.
  - 설정 → Windows → "수정키 드래그"에서 켜고 끄거나 수정키 조합(⌃ ⌥ ⇧ ⌘)을 바꿀 수 있습니다.
- **Clipboard: 서식 없이 붙여넣기 단축키** (#10, @gyuha)
  - ⌘⇧⌥V를 누르면 복사한 내용을 서식 없이 텍스트로 붙여넣습니다. 붙여넣은 뒤 클립보드의 원래 서식은 그대로 남습니다.
  - 단축키는 설정 → 일반에서 바꿀 수 있습니다.
- **팝오버에서 바로 업데이트**
  - 새 버전이 있으면 팝오버 아래쪽 설정 버튼 오른쪽에 노란색 **New update** 버튼과 새 버전 번호가 표시됩니다.
  - 누르면 업데이트할지 묻는 창이 뜨고(업데이트 / 나중에 / 릴리스 노트), 업데이트를 고르면 내려받아 설치한 뒤 앱을 다시 실행합니다.

## 개선

- **키 충돌 경고**: 다른 동작과 겹치는 키 조합 앞에 빨간 경고 아이콘이 표시되고, 마우스를 올리면 어떤 동작과 겹치는지 알려 줍니다.
  - 수정키 드래그에서 수정키를 하나만 고른 경우 (예: ⌥만 → Finder의 ⌥ 드래그 복사, 편집기의 열 선택이 창 이동으로 바뀜)
  - 서식 없이 붙여넣기가 ⌘⇧⌥V인 경우 (여러 앱의 "붙여넣고 스타일 일치"와 같은 키)
- **업데이트 실패 안내**: 설치에 실패하면 원인을 알려 주고, 업데이트 버튼이 그대로 남아 다시 시도할 수 있습니다.

## 버그 수정

- 수정키 드래그 사용 중 손쉬운 사용 권한이 꺼지거나 앱이 교체되면 클릭이 멈출 수 있던 문제를 막았습니다 (3초 안에 자동 해제, 권한이 돌아오면 자동 복구).
- 클립보드에 텍스트가 없을 때 서식 없이 붙여넣기를 누르면 다음 복사가 기록에서 빠지던 문제를 고쳤습니다.

## 업데이트 방법

- v0.1.2 이상: 팝오버의 **New update** 버튼 또는 설정 → 일반 → "지금 확인".
- Homebrew: `brew upgrade --cask t-utilities` (앱을 종료한 뒤 실행하세요).
