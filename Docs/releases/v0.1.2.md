## 새 기능 (Windows)

- **최대화 되돌리기** — 최대화(⌃⌥↩)한 창에서 한 번 더 누르면 원래 크기와 위치로 돌아갑니다.
- **위·아래 가장자리 끌어 높이 채우기** — 창의 위나 아래 가장자리를 메뉴 막대나 Dock 쪽 끝까지 끌면 반투명 미리보기가 나타나고, 놓으면 가로 크기는 그대로 높이만 화면에 맞춥니다. 끝에서 벗어나면 취소됩니다.
  - 높이를 채운 창을 좌우로 옮기면 높이가 유지되고, 위아래로 옮기면 원래 크기로 돌아갑니다.
  - 설정 → Windows에서 끌 수 있습니다.
- **macOS 화면 채우기 설정** — 설정 → Windows에서 macOS의 "창을 메뉴 막대로 끌어 화면 채우기"를 켜고 끌 수 있습니다.

## 버그 수정

- **앱 안 업데이트가 "설치 중…"에서 멈추던 문제** — 새 버전 설치 후 앱이 종료되지 않던 문제를 고쳤습니다. 설치 중에는 "지금 확인" 버튼이 비활성화됩니다.

## 알아둘 점

- v0.1.0·v0.1.1에서 이 버전으로 앱 안 업데이트를 하면 한 번은 "설치 중…"에서 멈출 수 있습니다. 활동 모니터에서 T-Utilities를 종료하면 새 버전이 자동으로 열립니다. Mouse 모듈을 쓰고 있다면 업데이트 전에 잠시 꺼 두는 것이 안전합니다. 또는 앱을 종료하고 `brew upgrade --cask t-utilities`를 실행하세요.
